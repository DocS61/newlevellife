# Namen-Reue-Rechner (Name Regret Calculator)

## Project Overview
A German-only utility website that analyzes baby names for potential issues (bullying risk, international pronunciation, career impact, trend analysis). Designed for AdSense monetization with minimal maintenance.

## Key Decisions
- **Single language**: German only. The user plans to create separate websites for English and Spanish versions (separate domains, separate codebases). This was chosen for:
  - Content reasons (different names per language)
  - Privacy/legal reasons (different DSE/consent requirements)
  - Technical reasons (server location, loading speed)
  - SEO reasons (optimized domains and meta tags per language)
- **Monetization**: Google AdSense (primary), no premium/subscription features
- **Hosting target**: Hetzner + Coolify (DSGVO compliance, German servers)
- **i18n system removed**: All text is hardcoded in German, no translation layer

## Technical Stack
- Modern web app with Tailwind CSS, Framer Motion
- Database with 168 pre-seeded names (Prisma)
- LLM API for analyzing names not in database (German prompts)
- Cookie consent banner (DSGVO-compliant)
- AdSense placeholder zones (hero-below, between-results, sidebar)

## Visual Style
- Gradient theme: coral-to-purple (hsl(340,75%,55%) to hsl(262,60%,55%))
- Fonts: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (monospace)
- Clean, card-based layout with subtle shadows
- Mobile-first responsive design
- Light theme default

## Pages
- `/` - Homepage with search, popular names, recent searches
- `/about` - Methodology explanation
- `/privacy` - Datenschutzerklärung (German privacy policy template)
- `/imprint` - Impressum (German legal notice template)
- Custom 404 page

## User Preferences
- Low maintenance after launch
- AdSense as primary revenue
- DSGVO compliance is critical
- Professional, trustworthy design for expecting parents
