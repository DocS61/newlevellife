# Name Regret Calculator (Namen-Reue-Rechner)

## Overview
A multi-language baby name analysis tool that evaluates names on 4 dimensions: bullying risk, international pronunciation, career impact, and trend analysis. Generates an overall "regret score" (0-100). Built for AdSense monetization.

## Tech Stack
- App Router with dynamic rendering
- PostgreSQL via Prisma for 168 pre-seeded names
- LLM API (gpt-5.4-mini) for streaming custom name analysis
- Full i18n (DE/EN/ES) via React context + translations object
- Framer Motion for animations
- Tailwind CSS with custom design tokens

## Color Palette
- Primary: `hsl(340, 75%, 55%)` (warm coral/pink)
- Secondary: `hsl(262, 60%, 55%)` (purple)
- Gradient: coral → purple for branding elements
- Score colors: green (≤30%), amber (≤60%), red (>60%)
- Warm neutral backgrounds

## Pages
- `/` — Homepage with search, autocomplete, popular names, recent searches
- `/about` — Methodology explanation
- `/privacy` — DSGVO-compliant privacy policy (DE/EN/ES templates)
- `/imprint` — Impressum (DE/EN/ES templates)
- Custom 404 page

## API Routes
- `GET /api/names/search?q=&exact=&limit=` — Autocomplete/exact search
- `GET /api/names/popular` — Top 12 by popularity
- `GET /api/names/random` — Random name
- `POST /api/analyze` — Streaming AI analysis for custom names

## Key Design Decisions
- Default language: German (target market for DSGVO)
- Language stored in localStorage, no URL-based routing for i18n
- Cookie consent banner appears after 1.5s delay on first visit
- Ad placeholders positioned: below hero, between results, sidebar (desktop)
- Score visualization: ring chart for overall, bar charts for categories
- Recent searches stored in localStorage
- Print-friendly via CSS `@media print`

## User Preferences
- DSGVO/privacy is critical (hosted in Germany)
- AdSense as primary revenue model
- Low maintenance after launch
- SEO optimized for organic traffic
- Modern, trustworthy design for expecting parents
