# Namen-Reue-Rechner (Name Regret Calculator)

## Project Overview
A German-only utility website that analyzes baby names for potential issues (bullying risk, international pronunciation, career impact, trend analysis). Designed for AdSense monetization with minimal maintenance.

## Key Decisions
- **Single language**: German only. The user plans to create separate websites for English and Spanish versions (separate domains, separate codebases). This was chosen for:
  - Content reasons (different names per language)
  - Privacy/legal reasons (different DSE/consent requirements)
  - Technical reasons (server location, loading speed)
  - SEO reasons (optimized domains and meta tags per language)
- **Monetization**: Google AdSense (primary), no premium/subscription features
- **Hosting target**: Hetzner + Coolify (DSGVO compliance, German servers)
- **i18n system removed**: All text is hardcoded in German, no translation layer

## Technical Stack
- Modern web app with Tailwind CSS, Framer Motion
- Database with 168 pre-seeded names (Prisma)
- LLM API for analyzing names not in database (German prompts)
- Cookie consent banner (DSGVO-compliant)
- AdSense placeholder zones (hero-below, between-results, sidebar)

## Visual Style
- Gradient theme: coral-to-purple (hsl(340,75%,55%) to hsl(262,60%,55%))
- Fonts: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (monospace)
- Clean, card-based layout with subtle shadows
- Mobile-first responsive design
- Light theme default

## Pages
- `/` - Homepage with search, features, "Wie funktioniert es?", Top 10, popular names, recent searches, "Wusstest du schon?", FAQ with Schema.org
- `/name/[slug]` - Individual name analysis pages (450+ indexable pages, biggest SEO lever)
- `/about` - "Über uns" page: Mission, Methodik, Datengrundlage, Team-Beschreibung (anonym), Hinweis. E-E-A-T trust signals.
- `/kontakt` - Kontaktformular mit Dropdown-Betreff, On-Screen-Bestätigung, API-Route /api/contact (logging).
- `/datenschutz` - Datenschutzerklärung (German privacy policy)
- `/impressum` - Impressum (German legal notice)
- Custom 404 page

## Navigation
- Header: Startseite, Blog, Über uns, Kontakt (Desktop + Mobile)
- Footer: Über uns, Kontakt, Datenschutz, Impressum + SmartUmrechnen.de Cross-Promo-Banner

## Blog
- `/blog` - Übersichtsseite mit Artikel-Grid (Kategorie-Tags, Emoji, Lesezeit, Datum)

  1. beliebteste-babynamen-2026 (Trends)
  2. seltene-vornamen-mit-schoener-bedeutung (Inspiration)
  3. babynamen-international-funktionieren (Ratgeber)
  4. tipps-fuer-die-namenswahl (Ratgeber)
  5. namensreue-vermeiden (Wissen)
  6. was-dein-vorname-ueber-dich-verraet (Wissen)
  7. alte-deutsche-vornamen-comeback (Trends)
- Artikelseiten: Prose-Typography, Vor/Zurück-Navigation, CTA zum Namensanalyse-Tool
- Daten: lib/blog-data.ts (Metadaten), lib/blog-content.ts (HTML-Inhalte)
- @tailwindcss/typography Plugin für Prose-Styling (auch in package.coolify.json)

## SEO Features
- Schema.org: FAQPage (homepage), WebApplication (layout), Article (name pages)
- Dynamic sitemap includes all name pages from DB
- Meta tags per page with German descriptions

## Score Display System
- All scores: HIGH = BAD (risk-based)
- ScoreBar: Risk badges (Niedrig ✓ / Mittel ⚠ / Hoch ✗) with green/amber/red
- ScoreRing: Emoji indicator (😊→😰) based on score level
- Blue info hint explains scoring direction
- Labels: "Mobbing-Risiko", "Aussprache-Schwierigkeit", "Karriere-Risiko", "Trend-Risiko"
- Descriptions clarify direction: "(Niedrig = kaum Risiko)" etc.

## User Preferences
- Low maintenance after launch
- AdSense as primary revenue
- DSGVO compliance is critical
- Professional, trustworthy design for expecting parents
